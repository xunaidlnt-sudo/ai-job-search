# Clean-room policy

Stratum is an independent product. It matches what other 4D tools do, not how they do it.

Allowed inputs when designing a feature:

- Public product pages, brochures, published help pages, training course outlines, conference talks and videos
- Open standards and their documentation: IFC (buildingSMART), Primavera P6 XER/XML, MSPDI XML, BCF
- Open-source libraries under licences compatible with Stratum (currently three.js MIT, web-ifc MPL-2.0, React MIT, zustand MIT)
- General construction planning knowledge (CPM, earned value, AACE / PMI practice)

Not allowed:

- Decompiling, disassembling, debugging or otherwise inspecting any competitor's binaries, installers or network traffic
- Reading or reverse engineering competitors' proprietary file formats
- Copying screenshots, icons, UI layouts, wording, help text, sample projects or brand names
- Using a competitor's software under a licence whose terms forbid this kind of use

Each feature in [PARITY.md](PARITY.md) cites the public source it was scoped from.
